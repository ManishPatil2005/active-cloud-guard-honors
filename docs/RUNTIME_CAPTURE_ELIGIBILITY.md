# Runtime capture eligibility checklist — draft 0.1

**DRAFT — NOT APPROVED.** Manual E2-035/RQ3 review aid, 6 October 2026; not a machine-validated eligibility policy or permission for collection/training. Current intake reports eligibility/fitting false. No row is pre-approved; each candidate needs referenced evidence, reviewer and decision. [Coordinator protocol](RUNTIME_LABELING_PROTOCOL.md).

Use satisfied / not satisfied / unknown / not applicable with an approved written reason. Absence of evidence is unknown, not satisfied. A not-applicable decision must match the narrow intended claim and supervisor approval, not evade an unfavorable result. Keep the original status/evidence of excluded and rejected runs. These gates are prerequisites to review, not an automatic score or all-purpose attestation.

## Required per-candidate record

Record candidate ID and data role, intended claim, original capture/source hashes, guideline/protocol versions, reviewer/date, one status and evidence reference per gate, unresolved limits, exclusions and next authorized action. The [case ledger](templates/runtime-case-ledger.md) is an unfilled starter, not accepted data. Store completed private records under private/runtime-labeling or approved secure storage.
